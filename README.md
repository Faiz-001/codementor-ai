# CodeMentor AI — Production SaaS Application

**Tagline:** Don't just fix your code. Learn why it broke.

CodeMentor AI is an AI-powered coding mentor built with the MERN stack (MongoDB, Express, React, Node.js) and powered by Google Gemini API.

---

## Features

- **Multi-source Code Input:** Monaco Editor integration supporting pasted code and source file uploads (.js, .py, .java, .cpp, .go, .rs, etc.).
- **Comprehensive AI Analysis:** Real-time bug detection, security audits, performance suggestions, and unit test generation.
- **Skill Profile Engine:** Dynamic developer score calculation tracking strengths and recurring weak areas.
- **Practice Challenges:** Dynamic AI-generated exercises targeting identified weak concepts.
- **Visual Analytics:** Recharts integration displaying score trends over time and language breakdown.

---

## Technology Stack

- **Frontend:** React, Vite, JavaScript, Tailwind CSS, Monaco Editor, Recharts, TanStack Query, Axios.
- **Backend:** Node.js, Express.js (ES Modules), MongoDB, Mongoose, JWT, Multer, Zod, bcryptjs.
- **AI Integration:** Google Gemini API (structured JSON output mode).
